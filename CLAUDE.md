# Pedal Playground

The app is in `web/` (React, Vite, Tailwind). Docs are in `docs/`.

## Consistency comes first

Any change to how something looks or works can leave a mismatch somewhere else on the site. Before finishing a
change, look for the other places that show the same thing (other dialogs, the gallery page, phone and desktop
layouts, light and dark mode, the auth emails) and bring them in line in the same change. If one should stay
different, call it out and ask. `docs/ui-conventions.md` lists the shared pieces and where each one is used.
